# Academy Cinemas 
## Overview
This repository contains the homepage interface for Academy Cinemas. It features a responsive single-page web design for browsing movie showtimes, purchasing tickets, and reaching out to cinema staff.   
## Features 
**Navigation Bar:**
- Sticky navigation for easy access to movie selections, 
- ticket purchases, and contact sections.   
**Now Playing Showcase:**
- Movie details, cast/director information, and showtimes for featured classics (Ben-Hur, The Day the Earth Stood Still, and Vertigo).   
**Ticket Selection Form:**
- A simple ticket purchasing widget to select a movie, 
- Time slot, and 
_ Ticket quantity.   
**Contact Form:**
- An integrated form for visitors to send messages directly.   
**Responsive Layout:**
- Designed using Bootstrap grid components along with custom styling for screen responsiveness.

# Simple Recipes
This project is a website featuring a collection of easy-to-follow recipes, complete with prep times, difficulty levels, and flip-card image effects.   

## Key Features

**Navigation:**
- Includes a main navigation bar with a rollover dropdown menu linking to specific recipe categories (Pasta, Chicken, Pork, Biscuits, Fish, Dessert) as well as About and Contact sections.   

**Featured Recipe:**
- Highlights a Deep Dish Skillet Pizza with prep time, difficulty rating, detailed description, and call-to-action button.  

**Interactive Recipe Cards:**
- Uses a front/back flip card layout for dish entries showing recipe images on the front and prep times/difficulty levels on the back:   
    - Saucy Tortelloni Parm   
    - Mediterranean Chicken Thighs   
    - Crispy Pork Katsu & Rice   
    - Cheddar Cheese Biscuits   
    - Baked Cod & Scalloped Potatoes   
    - S'mores Cake   

**About Section:**
- Provides background on the mission and story behind Simple Recipes.   

**Contact Form:**
-  Form collecting visitor details (name, email, phone number, custom message) and a checkbox option for weekly recipe subscriptions.   

**Footer:**
- Displays contact phone number, Portland address, and copyright details formatted inside a table layout.
